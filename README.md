# Стив в Зоне

Minecraft-строительство, крафт и бой в мире **S.T.A.L.K.E.R.: Тень Чернобыля**. Вы играете за Стива, а персонажи, диалоги, задания и деньги остаются из «Сталкера».

**[Скачать beta 0.4.0-beta.1](https://github.com/DeSoreGD/Steve-in-the-zone/releases)** · [English installation guide](README-EN.md)

Для игры скачайте **`Steve-in-the-Zone-0.4.0-beta.1-Windows-x64.zip`**.

## Что нужно

- **Windows 10/11, 64-битная.**
- Установленная **«Тень Чернобыля» 1.0006 без сторонних модов**.
- **Minecraft Java Edition**. Установщик скачает недостающие файлы **1.20.1** и Fabric с официальных серверов, а подходящие файлы из вашей папки Minecraft использует повторно. Bedrock Edition не подходит.
- **64-битная Java** для запуска Minecraft-части. Если установщик не нашёл подходящую Java, установите [Microsoft OpenJDK 21](https://learn.microsoft.com/en-us/java/openjdk/download#openjdk-21): **Windows x64 / msi**.
- Интернет для подготовки компонентов и место для отдельной установки.

## Как установить

1. Распакуйте весь Windows-архив и запустите **`InstallSteveInTheZone.exe`**.
2. Выберите папку «Тени Чернобыля», папку Minecraft Java Edition (обычно `%APPDATA%\.minecraft`), Java при необходимости и место установки.
3. После установки откройте **`app\SteveInTheZone.exe`** в созданной папке **`Steve in the Zone`** и нажмите **«Запустить игру»**.

Играйте в окне «Сталкера»; Minecraft работает в фоне. Исходные игры и сохранения сохраняются. Оригинальные игры и Java в архив не входят.

## Что важно знать

Это первая beta: полное прохождение сюжета ещё не подтверждено. Для боя и защиты используйте Minecraft-снаряжение — оружие и костюмы «Сталкера» пока не перенесены полностью. [Остальные ограничения](KNOWN-LIMITATIONS.md).

Если возникла проблема, [создайте сообщение об ошибке](https://github.com/DeSoreGD/Steve-in-the-zone/issues/new/choose). Укажите локацию и действия перед сбоем; [какие журналы приложить](REPORT-A-PROBLEM.md).
