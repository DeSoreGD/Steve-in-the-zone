# Сообщить о проблеме / Report a problem

Создайте сообщение об ошибке в этом репозитории. Укажите место сбоя и действия, после которых он возникает.

Укажите:

- Версию выпуска, режим Survival/Creative и версию исходной SoC.
- Локацию, NPC/предмет/название задания и что происходило перед ошибкой.
- Что ожидалось, что произошло и повторяется ли ошибка после F8.
- Последний журнал из `soc/_appdata_steve/logs`, `minecraft/demo-minecraft.log` и, если есть, `minecraft/demo-minecraft-error.log`.

Если проблема видна на экране, приложите снимок. Перед серьёзным экспериментом сохранитесь через F7. Для ошибки загрузки укажите, на каком шаге она возникла: установка, первый запуск, переход или загрузка сохранения.

Прикладывайте только относящиеся к ошибке журналы и снимки. Файлы аккаунта, аргументы запуска с токенами и всю папку Minecraft прикладывать не нужно. Парное сохранение можно передать отдельно, если оно потребуется для воспроизведения; обе части должны относиться к одному совместному сохранению.

## English

Open an Issue in the repository where you downloaded the beta. Include the release version, Survival/Creative mode, base SoC version, area, NPC/item/task, steps, expected and actual results, and whether F8 reproduces the problem.

Attach the latest log from `soc/_appdata_steve/logs`, `minecraft/demo-minecraft.log` and `minecraft/demo-minecraft-error.log` if present. A screenshot helps with visible defects. Save the pair with F7 before experimenting. For loading problems, identify the failing stage: installation, first launch, level transition or save restore.

Attach relevant logs rather than account files, launch arguments containing tokens or the entire Minecraft folder. A paired save may be requested separately; both parts must belong to the same checkpoint.
