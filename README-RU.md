# Стив в Зоне

Стройте, создавайте предметы и сражайтесь за Стива в мире **S.T.A.L.K.E.R.: Тень Чернобыля**. Персонажи, диалоги и задания остаются из «Сталкера»; инструменты, броня, крафт и блоки — из Minecraft.

Версия **0.4.0-beta.6**. Полное прохождение сюжета ещё не подтверждено. [Ограничения версии](KNOWN-LIMITATIONS.md).

## Что понадобится

| Компонент | Требование |
|---|---|
| Windows | Windows 10 или 11, 64-битная |
| «Сталкер» | **Shadow of Chernobyl («Тень Чернобыля») 1.0006**, без сторонних модов |
| Minecraft | Установленная **Java Edition**. Для проекта установщик скачает недостающие файлы **1.20.1** и Fabric с официальных серверов. Bedrock Edition не подходит |
| Java | 64-битная Java. Для новой установки рекомендуем **Java 21**; уже найденную совместимую Java 17+ можно использовать |
| Интернет и место на диске | Интернет для загрузки компонентов; место для отдельной копии файлов игр |

Оригинальные игры в архив не входят. Установщик создаёт отдельную папку проекта и сохраняет ваши исходные игры и сохранения.

### Зачем нужна Java

Minecraft Java Edition запускается с помощью Java. Она нужна и для Minecraft-части проекта, хотя играть вы будете в окне «Сталкера».

Если установщик нашёл подходящую Java, скачивать её повторно не требуется. Если нет, откройте [страницу Microsoft OpenJDK](https://learn.microsoft.com/en-us/java/openjdk/download#openjdk-21), найдите **OpenJDK 21 → Windows → x64 → msi** и установите его. Затем выберите в поле «Java» файл **`javaw.exe`** из подпапки **`bin`** установленной Java. У Microsoft OpenJDK папка установки обычно находится в `C:\Program Files\Microsoft` и начинается с `jdk-21`.

## Установка

1. В [Releases](https://github.com/DeSoreGD/Steve-in-the-zone/releases) скачайте **`Steve-in-the-Zone-0.4.0-beta.6-Windows-x64.zip`**. Архив `sources` предназначен для разработчиков.
2. Распакуйте **весь архив** и запустите **`InstallSteveInTheZone.exe`**. Файл запуска и папки `_internal` и `payload` должны оставаться вместе.
3. Выберите язык установщика и заполните поля по таблице ниже.
4. Нажмите **«Установить»** и дождитесь завершения. Установщик создаст собственную копию **Minecraft 1.20.1 с Fabric** внутри новой папки **Steve in the Zone**: подходящие файлы скопирует из указанной папки Minecraft, остальные скачает с официальных серверов. Наш лаунчер запускает эту отдельную копию в фоне. Вручную устанавливать 1.20.1 или Fabric через обычный Minecraft-лаунчер не нужно.
5. Если оставили галочку **«Создать ярлык на рабочем столе»**, запускайте игру через этот ярлык. Или откройте **`app\SteveInTheZone.exe`** в созданной папке **`Steve in the Zone`**. Выберите **«Выживание»** и нажмите **«Запустить игру»**.

| Поле установщика | Что выбрать |
|---|---|
| Папка S.T.A.L.K.E.R. SoC 1.0006 | Корневую папку установленной «Тени Чернобыля», где лежат файлы `gamedata.db…` |
| Папка установленного Minecraft | Папку данных Java Edition, обычно **`%APPDATA%\.minecraft`**. Нажмите Win + R и вставьте этот путь, чтобы открыть её. У другого лаунчера папка может отличаться |
| Java | Если поиск не сработал — файл **`bin\javaw.exe`** подходящей Java; см. раздел выше |
| Новая папка игры | Папку, в которой установщик создаст отдельную **`Steve in the Zone`**, например `D:\Games` |

Играйте в окне «Сталкера». Minecraft работает в фоне; отдельное его окно открывать не нужно. Первый запуск создаёт новую кампанию, следующие продолжают последнее совместное сохранение.

## Обновление предыдущей beta

Закройте игру и лаунчер. Распакуйте новый Windows-архив, откройте **InstallSteveInTheZone.exe**, включите **«Обновить установленную игру, сохранив прогресс»** и выберите существующую папку **Steve in the Zone**. Повторно выбирать исходные игры и Java не требуется.

Миры, совместные сохранения, предметы, имя игрока, настройки и другие Minecraft-моды сохраняются. Заменённые файлы проекта остаются в `update-backups`. При ошибке замены установщик восстанавливает прежние файлы. Автоматическое обновление поддерживает установки, созданные Setup; нестандартные рабочие копии не принимаются.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / Пробел | Перемещение / прыжок |
| Левая / правая кнопка мыши | Атака и добыча / использование предмета и установка блока |
| Колесо / 1–9 | Выбор предмета в панели быстрого доступа |
| E | Инвентарь; «Вещи Зоны» и «Задания Зоны» открывают вещи, PDA и задания «Сталкера» |
| G | Разговор, подбор и взаимодействие с дверью или механизмом |
| F5 | Вид от третьего лица |
| F6 | «Выживание» / «Творческий» |
| F7 / F8 | Сохранение / загрузка обеих частей игры |
| Esc | Закрыть текущий экран или открыть меню |
| F9 / Shift + F9 | Экспериментальный аварийный проход / возврат к месту его включения |

Для выхода закройте окно «Сталкера» и дождитесь сохранения. Не завершайте фоновый Minecraft отдельно: прогресс хранится совместно в двух играх. Перед переносом установки закройте обе игры и перенесите всю папку **`Steve in the Zone`**.

Справка с основными действиями появится после первого входа в игру. Её можно снова открыть через **E → «Справка»**.

## Первые шаги

Поговорите с Сидоровичем и следуйте исходным заданиям. Если персонаж не разговаривает, выберите пустую ячейку панели быстрого доступа и уберите оружие из второй руки. Меч, топор и лук тоже считаются оружием.

Флешки, документы, ключи и пси-шлемы находятся в **E → «Вещи Зоны»**. Пси-шлем действует по исходным сюжетным условиям, когда находится в этом инвентаре. Задания и карта доступны через **E → «Задания Зоны»**.

Minecraft-снаряжение и материалы продаются за рубли у Сидоровича и других исходных торговцев: откройте обычную торговлю и выберите **Minecraft**. Перед лабораториями запаситесь едой, стрелами и материалами. Деревья «Сталкера» не добываются как деревья Minecraft.

Перед переходом на другую локацию сохранитесь через **F7**. Если застряли, проверьте задание в PDA; F9 помогает выбраться из препятствия, но не выполняет сюжетные условия.

## Деньги и снаряжение

Магазины Minecraft используют **те же рубли, что и «Сталкер»**: покупки списываются из вашего кошелька Зоны. Опыт Minecraft нужен для зачарований и не является второй валютой.

Исходные награды за задания сохранены. Еда, стрелы и строительные материалы стоят как прежде. Кожа — стартовое снаряжение, железо — постепенное улучшение, алмазы — поздняя необязательная покупка. Железную броню дешевле скрафтить, чем купить готовой. В старых сохранениях деньги и предметы остаются; новые цены действуют на последующие покупки.

## Магазин Minecraft и лимит FPS

Товары разделены на строительство, декор, снаряжение, расходники, материалы и рабочие блоки. Выберите строку для покупки **1, 4 или 16 наборов**: количество предметов и общая цена в рублях видны перед покупкой. Подсказки объясняют назначение блоков: шерсть подходит и для отделки, и для крафта, лестницы — для подъёма, сундуки и печи сохраняют обычные функции Minecraft.

TNT продаётся у Сидоровича после завершения первого задания с бандитами, а также у поздних торговцев. Для поджигания нужно огниво. Кровати в собственных измерениях Зоны работают как безопасный декор и не назначают новую точку возрождения.

Лимит FPS в лаунчере применяется к обеим играм. Изменение `r_fps_lock` в настройках графики «Сталкера» передаётся фоновому Minecraft. **«Без ограничения»** снимает игровой лимит, но не гарантирует определённую частоту кадров. В меню на паузе сохраняется прежний лимит движка.
